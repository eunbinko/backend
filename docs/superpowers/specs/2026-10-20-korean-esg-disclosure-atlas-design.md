# 대한민국 ESG 공시 아틀라스 설계

## 목적

대한민국 기업의 매출 순위와 ESG 공시 자료를 지도로 탐색할 수 있는 공개 사이트를 만든다. 사용자는 기업 본사 위치의 지도 포인트와 보고서 표지를 실타래처럼 연결해 관계를 파악하고, 표지를 선택해 공식 ESG 보고서를 PDF 뷰어로 읽는다.

## 승인된 범위와 결정

- 매출 순위는 **2025 회계연도 국내 상장사 별도 기준 매출 상위 10개사**로 한다. 화면과 데이터에 회계연도, 별도 기준, 순위 출처를 표시한다.
- 초기 데이터는 브라우저 검색으로 조사하고 출처를 붙인 검증 가능한 데이터로 관리한다. 런타임 웹 스크래핑은 하지 않는다.
- 각 기업의 위치는 본사 위치를 대표하는 하나의 지도 포인트로 표시한다.
- 초기 버전의 보고서 표지 이미지와 PDF는 기업의 공식 주소를 사용한다. PDF 원문을 우리 서버로 복사하거나 결제 기능을 구현하는 일은 후속 범위다.
- 기업별 ESG 하이라이트와 자료 출처를 표시한다. 하이라이트는 보고서에서 발췌한 설명이며 ESG 등급이나 독립 평가로 오인되지 않도록 한다.
- Vue 프론트엔드와 FastAPI 백엔드로 구현하고 SQLite를 데이터 저장소로 사용한다.
- 사이트의 공개 첫 화면을 ESG 아틀라스로 바꾼다. 기존 로그인·게시판 API는 유지한다.
- 백엔드와 프론트엔드 구현은 각각 별도의 Git worktree에서 진행한다.

## 사용자 경험

### 탐색 화면

- 넓은 중앙 지도에 대한민국과 기업 본사 포인트 10개를 표시한다.
- 보고서 표지는 지도 양쪽에 세로로 배치하고, 각 표지와 지도 포인트를 실타래처럼 연결한다.
- 선택한 기업의 연결선과 포인트를 강조하고 다른 연결은 맥락을 잃지 않을 정도로 절제한다.
- 기업 정보에는 매출 순위, 매출액, 회계연도, 본사 지역, 보고서 연도, ESG 하이라이트 및 출처를 표시한다.
- 초기 진입 시에도 선택 기업이나 첫 안내가 분명히 보이도록 한다.
- 표지 이미지를 선택하면 화면을 벗어나지 않는 PDF 오버레이 뷰어를 연다. 뷰어에는 기업명, 보고서명, 공식 원문 링크와 닫기 동작을 제공한다.
- 공식 이미지 또는 PDF가 누락되거나 외부 서버가 삽입을 차단해도 지도와 다른 기업 탐색은 계속 동작한다. 오류 상태에서 공식 보고서 링크를 제공한다.

### 시각 방향

사이트를 일반 관리 대시보드가 아닌 **공시 아틀라스**로 표현한다. 넓은 중앙 한국 지도는 옅은 청회색 지형과 가는 행정 경계를 사용한다. 좌우 보고서 표지는 세로로 배열한다. 활성 기업을 잇는 한 줄의 색실을 시각적 중심으로 삼고 비활성 연결은 얇고 절제한다. 순위와 연도는 큰 숫자와 단정한 한글 고딕 글꼴로 편집물처럼 구성한다. 모바일에서는 보고서 표지를 가로 목록으로 전환하면서 지도 포인트와 연결 관계를 유지한다.

### 접근성

- 포인트와 표지는 마우스뿐 아니라 키보드로 선택 가능하게 한다.
- 색상만으로 순위나 선택 상태를 전달하지 않고 텍스트와 명확한 포커스 표시를 함께 제공한다.
- PDF 오버레이는 열릴 때 제목을 알리고 키보드로 닫을 수 있게 한다.
- 모바일 화면과 reduced-motion 설정을 지원한다.

## 데이터와 출처

기업 데이터에는 안정적인 식별자, 회사명, 2025 별도 매출액, 순위, 회계연도, 본사 주소·좌표, 산업, ESG 하이라이트, 각 항목의 출처 URL과 확인일을 저장한다. 보고서 데이터에는 회사 식별자, 보고서명, 보고서 연도, 공식 표지 이미지 URL, 공식 PDF URL, 원문 랜딩 페이지 URL 및 출처를 저장한다.

순위 조사 결과에 따르면 한국CXO연구소가 2025년 국내 상장사 1,000곳의 **개별(별도) 기준** 매출을 집계한 자료가 공개되어 있으며, 삼성전자가 24년 연속 1위이고 일부 기업의 순위 상승이 보도되었다. 실제 상위 10개 목록과 매출액은 구현 단계에서 검색으로 다시 검증하고, 순위 집계 자료와 기업별 사업보고서/DART 등 공시 근거를 데이터 출처로 기록한다. 초기 검색 참고자료: [2025년 상장사 매출 집계 보도](https://v.daum.net/v/20260406110202650).

보고서 URL은 회사 공식 사이트를 우선 사용한다. 공식 페이지가 제공하는 표지 이미지 URL을 쓰고 적절한 이미지 자산이 없을 경우 PDF 첫 페이지의 미리보기를 제공할 수 있는지 확인한다. PDF는 공식 URL을 브라우저 뷰어에 연다. 회사가 `frame-ancestors` 또는 `X-Frame-Options` 등으로 삽입을 차단할 수 있으므로, 이 경우 새 탭 공식 링크를 명확히 제공한다.

검색에서 확인한 공식 보고서 예로는 삼성전자 2025 지속가능경영보고서 PDF와 현대자동차 2025 지속가능성 보고서 PDF가 있다. 이는 출처 탐색의 예시일 뿐 최종 상위 10개사 목록을 의미하지 않는다. 참고: [삼성전자 2025 보고서](https://www.samsung.com/sec/sustainability/media/pdf/Samsung_Electronics_Sustainability_Report_2025_KOR.pdf), [현대자동차 2025 보고서](https://org3.hyundai.com/content/hyundai/ww/data/csr/data/0000000053/attach/korean/hmc-2025-sustainability-report-ko-v10.pdf).

주소 좌표와 보고서 표지/PDF, ESG 하이라이트는 서로 다른 출처를 가질 수 있으므로 필드 수준 출처를 보존한다. 순위 또는 보고서 자료가 검증되지 않으면 임의의 실데이터처럼 표시하지 않는다.

## 시스템 구조

### FastAPI 백엔드

- 공개 조회 API는 회사 목록, 순위 메타데이터, 보고서 정보, 출처를 반환한다.
- SQLite에 검증된 초기 기업과 보고서 메타데이터를 저장한다.
- 응답 모델에 화면이 필요한 기준연도, 매출액/단위, 본사 좌표, 공식 URL, 출처를 포함한다.
- 기존 인증 및 게시판 라우터에는 불필요한 변경을 하지 않는다.

### Vue 프론트엔드

- 공개 첫 화면을 ESG 아틀라스로 구성한다.
- 백엔드의 회사·보고서 조회 API를 호출한다.
- 한국 지도, 본사 마커, 실타래 연결선, 좌우 보고서 표지, 기업 정보 및 PDF 오버레이를 렌더링한다.
- 빈 데이터, 로딩, API 실패, 외부 표지/PDF 로드 실패 상태를 처리한다.

### 경계

- 백엔드는 순위 및 출처를 검증해 정규화된 조회 자료로 제공한다.
- 프론트엔드는 데이터 수집이나 순위 계산을 하지 않고 전달받은 좌표와 메타데이터를 시각화한다.
- 사용자는 초기 공개 자료 열람에 로그인할 필요가 없다.
- 후속 유료 PDF 기능을 위해 이번 구현에서 결제, 파일 업로드/보관, 접근 권한 시스템을 추가하지 않는다.

## 검증 기준

### 백엔드 pytest

- 초기 데이터에 상위 10개 기업이 있고 순위가 1부터 10까지 중복 없이 정렬되는지 확인한다.
- 각 회사의 회계연도·별도 기준·매출액·좌표·출처와 공식 보고서 필드가 응답에 포함되는지 확인한다.
- 존재하지 않는 보고서 연도 또는 잘못된 식별자 입력이 일관된 API 오류를 반환하는지 확인한다.
- 기존 인증 및 게시판 테스트가 회귀 없이 통과하는지 확인한다.

### 프론트엔드 Jest

- API 데이터가 지도 포인트와 표지 정보로 렌더링되는지 확인한다.
- 포인트 선택이 회사 요약과 연결 강조 상태를 갱신하는지 확인한다.
- 표지 선택이 올바른 공식 PDF를 오버레이에서 열고 닫기 동작이 작동하는지 확인한다.
- API 오류, 이미지 로드 실패, PDF 삽입 실패 시 대체 안내와 공식 링크를 표시하는지 확인한다.
- 키보드 사용과 작은 화면 배치에 필요한 상호작용을 확인한다.

## 구현 분할

1. **백엔드 worktree:** SQLite 데이터 구조와 초기 데이터, 출처가 포함된 읽기 API, pytest 테스트.
2. **프론트엔드 worktree:** Vue 아틀라스 화면, 지도·선 연결·표지·PDF 오버레이, 반응형/접근성 처리, Jest 테스트.
3. 두 작업이 공유할 API 스키마를 계획에서 고정한다. worktree는 현재 미커밋 인증 변경을 보존한 동일한 기준 스냅샷에서 각각 생성하고, 각 구현은 담당 경로만 수정한다.
4. 두 작업 완료 뒤 통합 worktree에서 전체 백엔드 pytest, 프론트엔드 Jest, 프론트 빌드를 실행하고 경계 동작을 검토한다.

## 범위 제외

- 보고서 PDF를 우리 서버에 복사·저장하는 작업
- 결제, 유료 구독, 인증 기반 보고서 권한
- 공식 ESG 등급 산출 또는 기업 간 ESG 성과 평가
- 매출 순위·보고서를 주기적으로 자동 수집하는 크롤러
- 매출 상위 10위 밖의 기업 검색 및 연도 전환 UI
